## 🚀 What is vamender?

vamender is a Windows tool that helps you fix broken scenes, clean up unnecessary files, and manage versions for Virt-a-Mate (VAM). If you use VAM, you know how easy it is for things to break or get messy. vamender handles all that automatically.

## 📚 How to Use vamender

### First Time Setup
1. Launch vamender after installation
2. Select your VAM installation folder (usually `C:\Program Files\Virt-a-Mate`)
3. Click "Scan" to analyze your current setup

### Repairing Broken Scenes
1. Open vamender
2. Click "Repair"
3. Select the scenes you want to fix
4. Let vamender handle the rest

### Cleaning Up Files
1. Go to "Cleanup" section
2. Review the list of unnecessary files
3. Click "Remove Selected" to free up space

## 🔒 Safety First

vamender always creates backups before making changes. You can restore your original files at any time using the "Restore" feature. Nothing is permanently deleted without your confirmation.

## 🆘 Troubleshooting

**Problem:** vamender won't start
**Solution:** Make sure you have Windows 10 or later. Try running as administrator.

**Problem:** Can't find my VAM folder
**Solution:** Check `C:\Program Files\Virt-a-Mate` or wherever you installed VAM.

**Problem:** Scenes still broken after repair
**Solution:** Try the "Deep Repair" option in vamender. This does a more thorough scan.

## 📝 Frequently Asked Questions

**Q: Will vamender delete my scenes?**
A: No. vamender only removes unused files and broken dependencies. Your scenes stay safe.

**Q: Can I undo changes?**
A: Yes. vamender keeps backups for 30 days by default.

**Q: Does vamender work with mods?**
A: Yes. It works with all standard VAM mods and add-ons.
